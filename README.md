# KISHORE — VK PORTFOLIO

**CSE • AI/ML ENGINEER • FULL-STACK DEVELOPER • DATA ANALYST**

A motion-first, high-performance personal portfolio website built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## 🚀 Key Features

- **VK Monogram Brand Identity**: Custom animated logo reveal (`V → K`), hover lift, and red underline.
- **Cinematic Loading Screen**: Full-screen white reveal featuring technical status ticker, progress line (`0% → 100%`), and smooth exit transition.
- **Hero Section**: Centered portrait photo (`/public/images/kishore.png`) positioned 100% crisp and visible above the heading words with a scroll-driven vanishing animation (`useScroll` / `useTransform`).
- **Intelligence Engine**: Interactive showcase covering Computer Vision, Generative AI & RAG, NLP & Code Synthesis, and Graph Machine Learning.
- **Data Analytics Dashboard**: `DATA → INSIGHT → DECISION` interface with live KPI cards, telemetry stream bar charts, and log tables.
- **Cinematic Horizontal Project Roller**: Drag/swipe/scroll horizontal carousel with spring physics, active center scaling (`1.35x`), and category filters (`ALL`, `AI / ML`, `FULL-STACK`, `DATA`, `GENERATIVE AI`, `NLP`, `COMPUTER VISION`).
- **Case Study Routes (`/projects/[slug]`)**: Deep technical software case studies detailing Overview, Problem, Architecture Diagrams, Tech Stack, Data Specifications, Metrics, Challenges, and Live Model Sandbox.
- **Custom Cursor & Accessibility**: Desktop custom cursor dot with hover labels and `prefers-reduced-motion` support.

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React

## 📦 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```
